# Alert Sound Files

Place your alert notification sound files in this directory.

## Recommended Sound
- **Name**: `alert-beep.mp3`
- **Duration**: 0.5-1 second
- **Format**: MP3, WAV, or OGG
- **Volume**: Moderate (system will apply device volume)

## How to Get a Sound File

### Option 1: Free Beep from Online (Quickest)
1. Visit https://freesound.org
2. Search "beep alert"
3. Download a free beep sound
4. Rename to `alert-beep.mp3`
5. Place in this directory

### Option 2: Generate a Beep
- Use online tone generator: https://www.szynalski.com/tone-generator/
- Generate 1000Hz sine wave for 0.5 seconds
- Download as MP3
- Save as `alert-beep.mp3` here

### Option 3: Use System Sound (No Download Needed)
The app will work without this file - it will use system vibration only.
